# Mental Math

Do multiplications faster than reaching for a calculator, using digit tricks instead of long multiplication.

Source: `https://youtu.be/1wAr2Kbe-GM` ("Mental Math #1"). Covers two-digit ×11, numbers ending in 5, and matched-first-digit pairs. Trick details in `references/tricks.md`.

## When to use

- Multiplying any number by 11 mentally
- Squaring two-digit numbers ending in 5 (75², 95²)
- Multiplying pairs like 44×46 (same first digit, last digits sum to 10)
- Drilling speed: answer first, verify with a calculator after

## Instructions

1. **Spot the pattern before computing.** Match the problem to one trick: ×11 → Trick A; both end in 5 → Trick B; same first digit + last digits sum to 10 → Trick C. Done when: exactly one trick named, or none (fall back to normal multiplication).
2. **Run the digit moves, left to right.** Split, add, carry — never do full long multiplication in your head. Done when: a candidate answer is spoken/written.
3. **Carry rule.** Any middle sum ≥10: write the units digit, carry 1 left, propagate. Done when: no uncarried two-digit block remains.
4. **Verify once, then drill.** Check against a calculator the first time per trick; after 5 correct reps, trust the trick and chase speed. Done when: 5 unaided correct answers per trick.
